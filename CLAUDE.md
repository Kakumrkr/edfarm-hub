# EdFarm Hub (hackathon build, about 2 hours total)

Ed Farm learners get real, verified project experience with Birmingham startups and nonprofits.
- ADMIN (Ed Farm staff): approves orgs, adds verified Ed Farm achievements to students, moderates.
- ORG (startup or nonprofit): registers, waits for approval, posts projects, picks applicants, marks work complete, leaves a review.
- STUDENT (Ed Farm learner): applies alone or with one teammate, works with the org over email, builds a public verified track record.

Full spec and session plan: `docs/PLAN.md`. Read only the sections the current session points to.
Start each session with `/session N` (see `.claude/skills/session`).

## How to work (time is the constraint)
- Build only the current session's scope. No extra features, no refactors, no test framework.
- Don't stop to ask questions. Pick the simplest option, note it in the final summary, keep going.
- Use one pattern everywhere (below). Don't add dependencies beyond the list.
- End every session with `npm run typecheck` passing and a git commit `session N: <summary>`.

## Stack (pinned and tested together)
- Next.js 16.4.6 (App Router, Turbopack), React 19.3, TypeScript.
- Tailwind CSS 4.3 via the `@tailwindcss/turbopack` loader in next.config.ts. Theme tokens go in `src/app/globals.css` (`@theme`). There is no tailwind.config file.
- Prisma 6 (`prisma@6`, `@prisma/client@6`) + SQLite. NEVER install Prisma 7 or 8 (npm "latest" is a v8 RC with a different config model). `prisma/schema.prisma` is given and validated. Do not redesign it.
- Auth: own JWT cookie with `jose` + `bcryptjs`. No NextAuth. No middleware or proxy file.
- zod v4, lucide-react icons, pdf-lib (seed resumes only), tsx (scripts).
- No shadcn or component libraries. Use our own small UI kit in `src/components/ui`.

## Next.js 16 rules (tested; differs from older training data)
- `cacheComponents` and `partialPrefetching` must stay OFF (already removed from next.config.ts). With them on, any page that reads cookies or the DB fails the build.
- `params`, `searchParams`, `cookies()`, `headers()` are async: `const { id } = await params`.
- Page props type: `PageProps<"/s/[id]">`. Layout props: `LayoutProps<"/">`. These are global helpers generated by `next typegen` (part of `npm run typecheck`).
- Mutations are Server Actions in `src/server/actions/*.ts` with `"use server"`. Call `revalidatePath()` after writes and `redirect()` to navigate.
- Forms: client components use `useActionState` from "react". Submit buttons use `SubmitButton` (useFormStatus). Simple one-click actions (approve, accept) use `<form action={action.bind(null, id)}>`.
- AGENTS.md (from create-next-app) says to read the Next docs first. The rules needed here are listed above. Open `node_modules/next/dist/docs/` only if an API actually errors.

## Project layout
- `src/lib/db.ts` Prisma singleton (globalThis cache for dev)
- `src/lib/session.ts` createSession / getSession / destroySession (jose HS256, httpOnly cookie `sq_session`, 7 days)
- `src/lib/auth.ts` getCurrentUser(), requireUser(roles?) (redirects to /login, or to the user's own dashboard on wrong role)
- `src/lib/constants.ts` roles, statuses, categories, labels, badge tones (values in PLAN.md section 3)
- `src/lib/config.ts` APP_NAME = "EdFarm Hub", DEMO_MODE, AI_ENABLED
- `src/lib/format.ts` csvToList, listToCsv, emailDomain, websiteHost, domainsMatch, formatDate
- `src/server/queries.ts` shared reads (seatsUsed, public profile, dashboards)
- `src/server/actions/{auth,org,post,application,student,admin,ai}.ts`
- `src/components/ui/*` UI kit, `src/components/*` app components, `src/app/*` routes (PLAN.md section 5)
- `prisma/seed.ts` full demo data (PLAN.md section 7)

## Security rules (every server action and route handler)
1. First line: `const user = await requireUser([...allowed roles])`.
2. Check ownership before any write: the org owns the post; the student is the lead or the teammate on the application.
3. Validate input with zod. Return `{ ok: false, error }` for user errors instead of throwing.
4. Never expose emails, resumes or passwordHash beyond PLAN.md section 4 rules R8, R9, R16.

## Design direction (fixed, don't explore alternatives)
Warm and trustworthy: a modern community-bank app crossed with a field notebook.
- Background stone-50, white cards, border-stone-200, rounded-2xl, shadow-sm, generous spacing.
- Primary emerald-700 (hover emerald-800). In progress: amber. Danger: red-600. Info: sky.
- Geist font (already loaded). Page titles text-3xl font-semibold tracking-tight. Helper text stone-500.
- "Verified by Ed Farm" is an emerald badge with the lucide ShieldCheck icon (achievements, approved orgs, completed work).
- Every list has an empty state. Every page works at 390px wide.
- The frontend-design skill (if installed) applies inside this direction. Don't redesign.
